A one-line roast of a smart fridge, written for the
[Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb)
bounty on [make.fun](https://make.fun).

## The line

> My fridge updated its firmware last night and forgot how to be cold until it restarts.

## How it works

`main.py` (Python 3.13 standard library only, no third-party imports)
writes exactly that one line — 86 characters — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`).
It is fully deterministic: every run produces byte-identical output.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
